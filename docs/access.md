# Доступ к Welcome Book

Сайт закрыт окном входа (`/`): логин + пароль. **Вход определяет версию** - Office или Retail.
Два вида входа: **именной** (в записи заполнен логин: нужны и логин, и пароль) и **общий** (логин не заполнен:
подходит любой логин, решает пароль).
Без входа `/office` и `/retail` отправляют на окно входа (`src/proxy.ts`).

## Пароли ведёт админ в Storyblok

История **Доступ (пароли)** (`access`). Каждый пароль - блок «Пароль доступа»:

| Поле | Что это |
|---|---|
| Кому | для себя: имя или команда, на сайте не показывается |
| Какую версию открывает | Office или Retail |
| Логин | необязательно. Заполнен - войти можно только с этим логином и паролем (регистр логина не важен). Пусто - общий пароль |
| Пароль | то, что вводят на странице входа |
| Действует до | необязательно, UTC. Пусто - без срока. По истечении пароль перестаёт работать |
| Отключить | закрывает доступ по паролю, не удаляя запись |

Изменения действуют в течение 30 секунд после **публикации** истории (черновик не работает). Удалили, отключили или
истёк срок - вошедшие по этому паролю выходят. Новый пароль можно добавить рядом со старым на время перехода.

Пароли лежат в Storyblok открытым текстом: их видят все редакторы пространства. Сайт читает их на сервере и в браузер
не отдаёт. Доступ к истории стоит ограничить в Storyblok.

Завести блоки и пустую историю в новом пространстве: `npm run storyblok:access`.

## Запасной вход (Vercel → Settings → Environment Variables)

| Переменная | Что это |
|---|---|
| `ACCESS_SECRET` | длинная случайная строка, подпись cookie. Без неё войти нельзя |
| `ACCESS_OFFICE` | пароли для Office, через запятую или с новой строки |
| `ACCESS_RETAIL` | пароли для Retail |

Эти пароли работают всегда, даже если Storyblok недоступен. Вместе с ними действуют пароли из Storyblok. Чтобы убрать
запасной вход, оставьте переменные пустыми, но `ACCESS_SECRET` нужен всегда. После смены переменных нужен redeploy.

Сессия живёт 30 дней или пока пароль, по которому вошли, действует.

## Что не защищено

Общий пароль (запись без логина и пароли из Vercel) пускает с любым логином. Учёта, кто и когда входил, нет:
для этого нужна база пользователей (например Vercel KV).

## Тексты окна входа

Редактируются в Storyblok: история **Вход** (`login`). Чего редактор не заполнил, берётся из `src/content/seed/login.ts`.
Завести блок и историю в новом пространстве: `npm run storyblok:login`.

Редактор Storyblok входит через `/api/preview` и получает доступ к обеим версиям без пароля.
